# Web Build для ASN WGPU

Этот документ описывает как собрать и запустить ASN WGPU приложение для web.

## Быстрый старт

### 1. Сборка

```bash
# Запустите скрипт сборки
./build-web.sh
```

Или используйте Makefile:
```bash
make web
```

Этот скрипт:
- Проверяет наличие `wasm-pack`
- Очищает предыдущие сборки (при использовании флага --clean)
- Собирает проект для WASM с помощью wasm-pack
- Создает файлы в директории `pkg/`

### 2. Запуск

```bash
# Перейдите в директорию web
cd web

# Запустите HTTP сервер
python3 -m http.server 8080
# или
npx serve .
```

Или используйте Makefile:
```bash
make run-web
```

### 3. Открытие в браузере

Откройте http://localhost:8080 в современном браузере.

## Структура файлов

```
web/
├── index.html          # Основная HTML страница
├── pkg/                # Собранные WASM файлы
│   ├── ex_web.js
│   ├── ex_web_bg.wasm
│   └── package.json
└── README.md           # Документация web версии
```

## Возможности

- ✅ WebAssembly модуль
- ✅ Асинхронная инициализация
- ✅ Современный UI
- ✅ Обработка ошибок
- ✅ Консольное логирование

## Требования

- Rust с поддержкой WASM
- `wasm-pack` (устанавливается автоматически)
- Современный браузер с поддержкой WebAssembly
- HTTP сервер для локальной разработки

## Отладка

1. Откройте Developer Tools в браузере
2. Перейдите на вкладку Console
3. Проверьте логи и ошибки

## Известные ограничения

- Web версия использует упрощенную логику без полного WGPU рендеринга
- Некоторые зависимости (rand, tokio) исключены из WASM сборки
- Для полной функциональности используйте нативную версию

## Сборка вручную

Если скрипт не работает, выполните команды вручную:

```bash
# Установка wasm-pack
cargo install wasm-pack

# Сборка
wasm-pack build --target web --out-dir pkg --release

# Запуск сервера
cd web && python3 -m http.server 8080
```

## Устранение неполадок

### Ошибка с getrandom
Если появляется ошибка с `getrandom`, это означает, что какая-то зависимость пытается использовать случайные числа. В web версии эта проблема решается с помощью флага `--cfg getrandom_backend="wasm_js"`, который задается в файле `.cargo/config.toml`.

### Ошибка с wgpu
Если появляется ошибка с `wgpu`, проверьте, что в `Cargo.toml` правильно настроены target-specific зависимости.

### Браузер не поддерживает WASM
Убедитесь, что используете современный браузер с поддержкой WebAssembly (Chrome, Firefox, Safari, Edge).
